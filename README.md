# 🛰️ Oil Spill Detection using Satellite Images

This project focuses on detecting oil spills in satellite images using a deep learning–based image segmentation model. It includes end-to-end implementation — from data preprocessing and visualization to model training, evaluation, and web app deployment using **Streamlit** and **Ngrok**.

## 📁 Project Structure

```
Oil-Spill-Detection/
│
├── 18b866a0-f70a-4081-82bc-c77e8ac0d5f9.ipynb   # Google Colab notebook (full pipeline)
├── streamlit_app.py                              # Streamlit frontend app
├── model/                                        # Saved model (.h5 or .keras)
│   └── oil_spill_model.h5
├── data/                                         # Dataset (images & masks)
│   ├── train_images/
│   ├── train_masks/
│   └── test_images/
├── results/                                      # Output predictions and visualizations
├── requirements.txt                              # Python dependencies
└── README.md
```

## 🚀 Features

- 🧠 **Deep Learning Segmentation Model** (U-Net / CNN)  
- 🛰️ **Satellite Image Processing** using OpenCV & NumPy  
- 📊 **Training Visualization** (loss, accuracy, Dice coefficient)  
- 🌐 **Web Deployment with Streamlit** (upload, predict, and view masks)  
- 📁 **Automatic PDF Report Generation** (optional using FPDF)  
- 🔗 **Ngrok Integration** for public app sharing from Colab

## 🧾 Running the Project in Google Colab

1. Open the notebook `18b866a0-f70a-4081-82bc-c77e8ac0d5f9.ipynb` in Google Colab  
2. Mount Google Drive (for dataset & model access)

   - Train and evaluate the model

## 🧩 Streamlit App Overview

The web app allows:
- 📤 Uploading satellite image files (`.jpg`, `.png`, `.tif`)
- 🧮 Running oil spill prediction using the trained model
- 🖼️ Viewing original vs segmented output
- 📄 Downloading optional PDF report of prediction

## 🧠 Model Summary

- Architecture: U-Net  
- Input size: 256×256  
- Loss function: Binary Crossentropy + Dice Loss  
- Metric: Dice Coefficient  
- Optimizer: Adam
